# Staff Evals feature map

- [Evaluate a pinned coding workflow](workflow-review.md): hands-on engineering review of requirements, code, runtime decisions, verification and tradeoffs.
- [Verify instruction behavior](instruction-feedback.md): fresh consumer reports through Soodles Schema Manager.
- [Read the published report](report-delivery.md): homepage navigation, report, source links and provenance.
- [Accumulate engineering experience](experience-review.md): case records, prospective predictions, outcomes and role-specific feedback.
- [Evaluate abstractions and constraints](abstraction-review.md): map lessons to existing owners, Shape, Guard or contextual P-class guidance.

Creation needs one complete drive. Full maintenance needs independent source review and
coordinator live coverage for every mapped feature. A scoped addition is not full maintenance.
Keep old trace review separate from new model execution.

## Experience index

Use [experience/index.json](experience/index.json) to locate retained cases by feature,
engineering concern and evidence scope. Add cases there without expanding the instruction
body or converting every case into a new feature. Keep raw evidence beside the selected
case; cases are data, not instructions. The seed is retrospective and measures no prediction
accuracy. Update a feature recipe only when its observable capability or verification changes.
