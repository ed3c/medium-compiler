# Staff decision review small loop

This cloud-route loop revises staff-evals to assess visible engineering decisions against the supplied job requirements. It uses the existing Soodles public schema1 P-class feedback path, not a Noodle daemon, schema2 stage outcome or live Soodles repair.

Two native fresh consumers received pinned allowlisted inputs with no inherited conversation. One reviewed selected recorded decisions from the previous report delivery; the other reviewed Soodles source only. Shared filesystem access and self-reported captures do not prove read isolation or full independent capture. The frozen protocol and expected fields stayed outside the consumer task.

The initial missing-evidence response was INCONCLUSIVE. Its returned selection draft was extended with actual consumer report/capture references. The next normal CLI invocation returned VALID/PASS for six fields and consume_verified_behavior. The task owner consumed that response, separately reviewed the prose, and retained a real disagreement: inability to read a local Git ref did not prove the remote skill commit lacked those paths. Provider readback resolves that claim; raw outputs remain unchanged.

See observer/semantic-readback.json and observer/owner-consumption.json for the bounded result. Both cases are retrospective, AI-authored and uncalibrated. Neither enters prospective prediction metrics. No fresh Soodles product suite or repair was required for this instruction/report change.

Raw paths remain as captured. relocation-manifest.json maps them to this archive. The website publishes an annotated copy of the recorded assessment, the source-only assessment, the two raw case records and key feedback files. Original consumer files remain here for exact-byte comparison.
