# Fast passive encounter

## User flow

1. See the term and pronunciation/stress cue.
2. Reveal or hear one article-specific core meaning.
3. Move on instead of memorizing every sense.
4. On a later probe, try to recognize the meaning before reveal.
5. Mark recognized to retire it from the current queue, or re-encounter it.

## Boundary

Recognition is still passive. Productive use is exercised only when `cefr-alg-four-pass` selects
the term for the smaller active set and uses it in Pass 4.
