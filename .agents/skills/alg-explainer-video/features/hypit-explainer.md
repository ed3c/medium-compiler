# Frozen lesson explainer

## Sub-features

- consume one immutable four-pass lesson package;
- use supplied narration without rewriting it;
- turn semantic visual anchors into diagram/state-transition scenes;
- bind visual events to words or semantic moments when timing supports it;
- retain a claim-to-narration-to-visual correspondence record.

## How to get to it (user POV)

Ask to turn a compiled CEFR ALG technical lesson into an explainer video. The semantic lesson must
already exist. If the request starts from an article, run `cefr-alg-four-pass` first.

## Driving it with Hypit

Read the frozen handoff. Use the installed Hypit skill/runtime rather than copying Hypit's production
instructions here. Build the smallest composition that explains the selected claims. Prefer
code-rendered diagrams for architectures and processes. Use supplied narration as retained audio when
available. Render only when the runtime is actually available.

After composition, trace each meaning-bearing visual event back to its frozen claim and narration
anchor. Preserve the workflow and render evidence requested by the task.

## Gotchas

A polished video can still reverse causality or erase uncertainty. Word synchronization proves timing,
not meaning. A video watched repeatedly is still receptive input; Pass 4 requires learner generation
and oracle comparison. Missing render capability is a blocked renderer, not permission to fabricate a
video receipt.
