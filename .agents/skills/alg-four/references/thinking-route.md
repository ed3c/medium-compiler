# Thinking Route for source-grounded English annotation

Follow Soodles Thinking Router **V2 first**: Goal, Measurement, Effort Horizon, First Causal Breakpoint; V3 only if a different falsifiable hypothesis would change the route. This is not an additional router or per-word LLM decision.

**Goal** — Maintain the original technical article unmodified, annotate each paragraph with context-accurate zh-TW and English terms, and progressively acquire 2000 source-grounded reusable Active words/phrases with 2000 linked English engineering sentences across articles.

**Measurement** — Verified original Git blob, per-paragraph note coverage, deduplicated active corpus size, source-backed sentence/decision linkage. Measure real learner recall accuracy, response latency, condition/negation and delayed recall only after actual attempts.

**Effort Horizon** — Annotate the selected article without re-authoring, re-rendering frozen upstream videos, scheduling reviews, writing learner profiles or inventing large corpus data.

**First Causal Breakpoint** — Earlier alg-four generated new `pass1/pass2/pass3` versions of the original. That destroys the same-narrative knowledge connection the user needs. Replace that path with a source-locked inline overlay.

**V2 route** — If a term is unfamiliar, add one concise contextual meaning. If a crucial decision needs English output, attach a source-faithful complete English sentence and a recall cue. If response loses a key condition, compare it with the source-bound meaning oracle. Do not build a new pass-specific article or reroute every sentence through an LLM.

**V3 only if necessary** — Check a proposed note for a counterexample such as `"a"` vs `"aa"` or unhashable tuple contents; correct that note rather than silently changing the underlying article. No new evidence or decision change means NOOP.

The four encounters are different cognitive acts on **the same text**, not a claim of a scientifically proven neural threshold exactly at fourth exposure.
