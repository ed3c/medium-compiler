## Bounded V3 and ambitious cross-check

- First Principles: Graph facts, owner-accepted evidence and renderer style are
  separate layers; SVG output cannot establish a causal edge.
- Adversarial Review: test stale/wrong digest, inline raw content, cross-origin,
  missing artifacts, unreviewed SVG and historic unknowns.
- Ablation: do not add a second React Flow authority, streaming bus, static
  dashboard server or hard performance threshold without measured benefit.
- Occam's Razor: reuse Noodle's canonical geometry and the article's
  existing site-build/image pipeline.
- High Cohesion/Low Coupling: original Publisher owns public disclosure;
  browser reader verifies exact published artifact bytes; article renderer
  consumes already-approved Markdown without writing its source.
- Ambitious Depth: require real candidate SVG creation, mobile/browser review,
  precise source fidelity and explicit limits to a merely visual PASS.
- Ambitious Altitude: useful result is causal trace comprehension from original
  Source/Runtime Evidence, not the number of rendering libraries installed.

These are review findings, not a new executable prompt, Stage, P-class
condition, admission token, Owner or effect authority.

## Acceptance and refusal

Source/CI pass is not a verified native Agent execution or whole-goal
acceptance. A synthetic Browser fixture is not a genuine Runner readback.
An existing writer/ALG Four browser run validates those preserved views,
not automatically a fresh Mermaid figure in a real newly reviewed article.

Only declare the independently completed layers after reading their exact
PR head CI/Browser artifacts. A registry with zero reviewed Mermaid
candidates proves the converter contract, not visual acceptance of a
newly generated published SVG. No Production deployment or live stream
until selected by its original authorized Owner. Keep PR #72 Draft if
native evidence, production readback or applicable original gates remain
NOT_RUN or UNKNOWN. An unknown side effect requires authoritative readback.
