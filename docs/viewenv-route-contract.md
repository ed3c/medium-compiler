# ViewEnv Route — decision-complete design (Q1–Q15)

Selected 2026-10-18, under original Soodles Thinking Router V2,
with one bounded V3 source/topology adversarial cross-check.
The User accepted all Q1–Q15 choices. No extra design questioning is required.

## Goal and scope
Generate *design artifacts plus a real environment interface*, not another
execution scheduler. The first end-to-end selected reference is an
evidence-backed NeoWeaver Harness Optimization Environment, rooted in an
actual Soodles decision failure. Preserve actual original Task rights and
Oracle; do not select a semantic failure from a timestamp or UI label.

1. Bound the Proposer's action surface to Skill Instruction, Context Policy
   and MCP Wrapper, one causal target, original allowlist. Other Harness²
   components remain deferred, not prohibited forever.
2. Isolated episodes, original reset identity, seed policy and budgets,
   external original readback and cleanup. Never carry environment state
   across episodes; retain only admissible lessons, receipts and artifacts.
3. Independent terminal verification is the canonical reward source;
   optional original step diagnostics do not imply RL reward or PASS.
   Unknown reward remains null and untrainable.
4. First prove original H0/H0 native transport and parser Oracle; then run
   a fixed-solver, fixed-conditions H0/H1 against a selected witnessed
   decision barrier. Single bounded Harness² k=1 Propose–Probe–Compose.
   Do not adopt upstream unrestricted-network or disabled-sandbox defaults.
5. Integrate NeoWeaver's existing `native.run_native_arm`,
   `native.inspect_native_pair`, `replay.inspect_pair`, `patches.parse_proposal`
   rather than creating a second verifier or runner.
6. Shared Environment Domain with OpenEnv adapter and Verifiers interface
   first; ORS and NeMo Gym adapter contracts are deferred until evidence
   demands them. Framework-specific serializers do not own domain state.
7. TanStack Start isolated preview with source-bound Actual / Proposed /
   Replay: one canonical object identity with independently colored/marked
   evidence layers. Public website read-only; authenticated private
   experiments use original Owner/Host Admission only.
8. Production promotion, RL Training and model registry effects are
   separate authorized phases. No claimed PASS without original readback.

## View design producer -> consumer

Original Owner Source -> exact-byte local Compiler -> Design Artifact
-> versioned View Contract -> design-time selected Skills
-> TanStack Start/Anatomy render -> browser/source checks.

The Design Compiler **selects** the requested main Skill deterministically;
it does not execute Skills, emit a fresh programmatic inference, invent
a harness status, create an execution next or publish publicly.

| View | Primary | Required input | Produced presentation | Verification |
| --- | --- | --- | --- | --- |
| Public narrative | Taste | reviewed public evidence and editorial goal | visual language + web explanation | Browser visual/source review |
| Live operations | Impeccable | native DAG/counters/states/authority | accessible information architecture | keyboard, mobile, source states |
| Machine anatomy | Anatomy | source-bound Objects/Ports/causal edges | versioned isometric mechanism | geometry plus trace parity |
| Motion audit | Emil | observed transitions only | animation tokens/reduced-motion | timing + reduced-motion |
| Trace annotation | build-review-interface | already-authorized trace | review-only annotation | reviewer and Oracle separation |

The User agreed that Skills are design-time compilers/reviewers,
not skills invoked every RL Step. Secondary skill reviews are opt-in
per observed problem; no four-Skill mandatory chain.

## Product Artifact
`ViewEnvDesignV1` is content-bound to original Source bytes
(and origin relative path) with `mode`, one `primary_skill`,
explicit secondary skills and `status=planned`. It never carries a
runtime ID, Operator/Session permission, live task success, training
reward or executable command. Original Native Repo IDs remain in
Loop v2 Graph, not recomputed in the design artifact.

## Source / native proof ceiling
- NeoWeaver OpenEnv and Verifiers adapters consume the same proposed
  domain and original parser. No provider-sourced native model run
  is claimed until external original logs confirm.
- Existing NeoWeaver native H0/H0 and matched-pair controls are separate
  evidence: a source-only smoke test cannot establish cost/gain/isolation.
- TanStack Start CI build does not validate browser behavior/hosted
  deployment or canonical Noodle SVG geometry parity.
- Credential / private source / held-out access belong to original Owner.
  The view cannot read them without an admitted private Session.
