The Software Factory cards describe a worker writing tests and code before handoff. Under the proposed separation, those self-tests must not be the sole basis for acceptance. A separate Scrutiny Validator reads the code. A separate User-Testing Validator checks the running application against the contract without reading the source. If a button does not produce the effect required by the contract, passing self-tests does not establish acceptance. That is a contract-checking example, not proof that dual validation prevents every failure. The cards leave the definition of done for long, open-ended tasks unresolved.
