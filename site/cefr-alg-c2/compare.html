How to compare fairly

Use the same script and playback volume. Voices differ between models, so this compares complete listening experiences, not only model architectures. RTF is generation time ÷ audio duration: lower is faster. Loading is recorded separately and can include downloads. Published timings are single runs on a shared CPU host, not controlled hardware benchmarks. First-use initialization may still affect generation.

Ratings are your listening notes, not automated quality or CEFR scores. They stay in this tab until downloaded. Hide names shuffles cards; voice identity can still reveal a model.

Generate the other voices locally

Published samples play without a model download. To generate another script, start the local Voice Lab from the repository. Model downloads happen on your computer; no hosted inference key is used.

python3 scripts/voice_lab_server.py

Then open http://127.0.0.1:8765/compare.html. Install each engine with python3 scripts/setup_voice_lab.py ENGINE. For offline transfer, import the resulting JSON and WAV files into a matching card.
